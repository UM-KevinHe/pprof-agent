# The demo data set

`demo/` is one synthetic measure file shaped like a CMS dialysis quality measure: one row per patient-month, the outcome `HOSPITALIZED`, a facility and a patient identifier, ten risk adjusters. It was generated by `sim/make_examples.R` from a model with known facility effects (`truth.json`: six facilities truly worse, four truly better, two with no events, a decoy with a much sicker case mix and no true departure). **Nothing here derives from real data.**

`dictionary.md` describes the columns, `specification.json` is a published specification the agent can pre-fill from, `scenarios/*.txt` are the scripted conversations (one message per line), and `runs/<scenario>/` the recorded runs with the local model that the web app replays.
