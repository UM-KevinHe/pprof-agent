# pprof Agent

A language-model agent for provider profiling (CMS dialysis measures): the analyst declares the measure in plain
language, the harness derives what the data admit, the model plans the analysis one verified step at a time, and
the report cites every number by a named reference the engine fills in.

This Space replays recorded runs on **synthetic** example data (no real patient or facility data). Each run holds the
conversation as it was shown, the flags under every admissible configuration, the figures, the report and the audit trail.
